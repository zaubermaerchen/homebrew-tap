# Homebrew Tap

Homebrew formulae for command-line tools by [zaubermaerchen](https://github.com/zaubermaerchen).

## Install

Install a formula directly from this tap:

```sh
brew install zaubermaerchen/tap/khsier
```

Alternatively, add the tap first:

```sh
brew tap zaubermaerchen/tap
brew install khsier
```

## Available formulae

### khsier

A small stream-boundary observer for Unix pipelines. It copies stdin to stdout byte-for-byte and emits lifecycle events such as BOS, IDLE, RESUME, and EOS.

Project: https://github.com/zaubermaerchen/khsier

```sh
brew install zaubermaerchen/tap/khsier
```

## Upgrade

```sh
brew update
brew upgrade khsier
```
